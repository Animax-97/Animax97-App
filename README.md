## 📲 Como Baixar e Instalar no Android

1. Acesse a [**página de lançamentos (Releases)**](https://github.com/Animax-97/Animax97-App/releases/latest) ou [**animax-97.github.io**](https://animax-97.github.io/).
2. Em **Assets**, toque no arquivo **`Animax97-v1.0-release.apk`** para baixar.
3. Abra o arquivo `.apk` baixado no seu celular.
4. Se o Android exibir o aviso *"Permitir instalação de apps desta fonte"*, toque em **Configurações → Permitir desta fonte** (esse aviso é padrão do Android para qualquer app baixado fora da Play Store).
5. Conclua a instalação e aproveite!
